# 1.14.0 验证范围

发布验证包含以下项目：

- 选择界面语言后立即切换和独立保存；10 种语言及系统语言映射；保存失败回退；其他设置草稿、原文、模型输出与标注保持不变。
- 10 种语言的设置和阅读窗口，包含窄窗口布局。
- 冻结 EXE 离线 OCR、识别子进程、设置与结果窗口、原生快捷键、截图工作区、贴图与首次启动。
- 安装到项目内的中文空格路径，包括预先存在的空文件夹；目录内数据存储、升级和卸载保留用户文件。
- 便携 ZIP 完整性与隔离运行；独立源码解压、环境初始化与测试。
- 公共源码和二进制包的配置排除、密钥形状及本机路径扫描。

自动测试日志和机器报告由构建脚本生成在 output 或 .tmp，不随公共源码发布。本版未逐家测试所有在线账号、模型和服务质量；多语言文本欢迎社区校对。

本地验证不等于完整 Windows 10 / 11 干净系统、多屏混合 DPI、不同显卡与输入法组合均已验证。GitHub Actions 工作流随源码提供，远程运行结果以仓库 Actions 页面为准。
