# SnapTrans 1.14.0 使用说明

## 首次使用

安装到可写文件夹，或完整解压便携包。运行 SnapTrans.exe 后先进入设置。默认晴空蓝、本地文字识别、MyMemory 翻译、界面语言跟随系统。配置服务和阅读偏好后，点击右上角“保存更改”。

界面语言在“偏好设置”中选择，选中立即切换并自动保存，无需点击保存或重启。源语言和目标语言可提前设置；它们与界面语言相互独立。语言和快捷键的自动保存不会提交其他未保存的配置。

## 截图与贴图

- F2：截图；默认自动识别并翻译。设置中可以关闭自动翻译。
- Alt+W：本次仅截图。两个快捷键都可录制修改，松键自动保存。
- 框选后工具栏直接显示标注、复制、保存、贴图、提取文字与翻译。
- 绘图工具可调整线宽，橡皮擦和涂抹马赛克可调整范围；颜色面板直接点击选择。
- 贴图可拖动、滚轮缩放、裁剪和标注；原文贴图也能直接翻译，无需回到原截图位置。
- 翻译后的贴图可以对照原图；返回工作区会关闭该贴图，其他贴图保留。
- Ctrl+0 按原始物理像素显示；Ctrl+9 适应屏幕。缩放不会改变原始图像及导出的像素数。在移动模式按 Alt 拖动可查看超出窗口的部分。
- OCR 使用原始截图，贴图上的裁剪、马赛克和标注不会改变发送给 OCR 的图片。

## 翻译服务

从分类卡片进入具体服务，设置地址、模型和所需凭据。每个服务保留自己的配置；切换选择后未保存就关闭设置，仍使用旧配置。连接测试只发送公开短句。

网页翻译包含 Google、Bing、百度、有道、DeepL、腾讯。可用性取决于网站、网络和账号状态。需要登录或验证时打开网页处理；不会绕过验证码。当前有道和腾讯网页适配器仅支持英译中，其余服务也可能有各自语言限制。MyMemory 需要明确源语言。

本地模型先启动服务并加载模型。Ollama 常用根地址为 http://127.0.0.1:11434/v1；LM Studio 常用 http://127.0.0.1:1234/v1。模型名称与正在运行的模型一致。

## OCR 与学术模式

默认本地 OCR 无需连接云端，附带模型主要识别中文和英文。其他语言可选择相应的视觉模型。云端 OCR 独立保存模型、地址和凭据，测试只发送公开示例图片。

学术提示词在独立页面查看。先点击修改并确认，再编辑；点击保存并确认后才启用。普通翻译服务不使用大模型提示词。

## 安装、升级与数据

程序和模型位于安装目录，配置、密钥、日志、网页缓存和应用临时文件位于旁边的 data。默认无系统注册项或快捷方式；安装向导中的系统集成与桌面快捷方式可选。Windows 自己的运行记录和安装器系统临时文件不在本应用的控制范围内。

升级前从托盘退出旧版。安装版选择原目录；便携版解压到新目录，按需复制旧 data。卸载只移除已记录的程序文件，保留 data 和其他用户文件。确认不再需要后可以手动删除残留数据。不同用户或电脑不能直接解密原 Windows 用户加密保存的密钥。

旧版 1.11.0 若将数据保存在 %LOCALAPPDATA%/SnapTrans/data，可退出旧程序并自行备份、复制到新目录。应用不会自动读取或删除旧目录。

安装包未做 Authenticode 签名。请从项目 Release 下载，并用同页 SHA-256 核对文件完整性。
